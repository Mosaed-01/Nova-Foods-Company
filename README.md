# Nova Foods — International Food Trading & Distribution

Official website for **Nova Foods**, a dynamic international food trading and distribution company headquartered in Yemen, connecting global producers with emerging markets.

🌐 **Live Site:** [mosaed-01.github.io/Nova-Foods-Company](https://mosaed-01.github.io/Nova-Foods-Company/)

---

## About

Nova Foods specializes in the import, export, and wholesale distribution of high-quality food products sourced from trusted global manufacturers across Asia and the Middle East.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Arabic / English bilingual support with RTL layout
- Smooth scroll animations and counter effects
- Interactive Yemen map with city markers
- Contact form with mailto integration
- WhatsApp floating button
- Animated page loader

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, animations
- **Vanilla JavaScript** — no frameworks or dependencies
- **Font Awesome 6** — icons
- **Google Fonts** — Playfair Display, Inter, Cairo, Amiri
